# Figma Screen Contracts

Folder ini adalah source of truth implementasi frontend per screen.

Authority:

- exact visible copy → Screen Contract
- content hierarchy → Screen Contract
- screen structure/layout → Screen Contract
- button/action behavior → Screen Contract
- visual styling → Docs/RefrensiHTML/DESIGN.md
- global UX/accessibility → Docs/ai/02-UI-UX-DESIGN-BRIEF.md
- product/business requirement → Docs/ai/01-PRD-HIRU-ACADEMY.md

## Copy Fidelity

Semua visible text dari Figma harus disalin verbatim.

Termasuk:
- heading
- paragraph
- button
- label
- navigation
- badge
- placeholder
- helper text
- modal
- empty state
- status
- error/success message

Jangan rewrite, paraphrase, memperpendek, memperpanjang, atau memperbaiki copy.

Kapitalisasi, punctuation, angka, simbol, dan Japanese text harus dipertahankan.

## Contract Status

VERIFIED
= screen sudah diperiksa langsung terhadap Figma.

PARTIAL
= sebagian informasi sudah diverifikasi tetapi masih ada bagian OPEN.

OPEN
= belum diverifikasi.

OpenCode hanya boleh menganggap copy sebagai client-approved jika contract berstatus VERIFIED.

Jika informasi tidak tersedia, tandai OPEN. Jangan mengarang.
